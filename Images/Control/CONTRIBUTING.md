# Contributing to HTML Project Launcher

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## 🐛 Found a Bug?
If you find a bug in the source code, you can help us by submitting an issue to our repository. Even better, you can submit a Pull Request with a fix.

## 💡 Missing a Feature?
You can request a new feature by submitting an issue. If you would like to implement it yourself, please submit an issue first with your proposal so we can ensure it aligns with the project's goals.

## 🛠️ Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing style and architecture (e.g., standard Tkinter UI components, no heavy external libraries).
3. Test your changes locally on your operating system.
4. Update the `README.md` if your changes require new instructions.
5. Issue the pull request!

## 📜 Coding Guidelines
* Keep it lightweight. This project prides itself on having zero external runtime dependencies. 
* Use native Python libraries (`os`, `sys`, `tkinter`) whenever possible.
* Comment complex logic, especially anything involving cross-platform OS calls.
